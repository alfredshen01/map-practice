# 地圖練習

在世界地圖上找國家的練習遊戲：探索地圖、回合練習與熟練度、知識卡（首都、語言與問候語、國旗、面積與人口、氣候、植被、殖民史），以及多種地理小遊戲。

- 網址：https://alfredshen01.github.io/map-practice/
- iPhone：用 Safari 開啟 → 分享 → 加入主畫面，就能像 App 一樣全螢幕開啟，第一次開啟後可離線使用。
- 進度只存在你的瀏覽器裡，換裝置不會同步。

這個 repo 只放建置好的網站（版本 v39）。
